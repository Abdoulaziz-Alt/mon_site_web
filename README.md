# Lucky Jet Predictor

Site web de prédictions pour le jeu Lucky Jet.

## Fonctionnalités
- Entrée d’un code d’accès pour accéder aux prédictions.
- Génération de prédictions aléatoires entre 1.00 et 60.00.
- Interface simple et interactive.

## Structure du projet
- index.html : page principale
- about.html : page “À propos”
- contact.html : page de contact
- style.css : fichier de style
- script.js : logique des prédictions
- images/ : images utilisées
- fonts/ : polices personnalisées
